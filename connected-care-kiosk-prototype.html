How it works

  1. Idle loop — muted looping video; buttons + touch hint visible.
  2. Floor trigger → the intro video plays, then back to idle.
  3. Buttons — each plays that person's story video, then back to idle.
  4. 3rd video → the Connected Care Outcome screen, then back to idle.
  5. Lock order (optional) — buttons must be tapped 1 → 2 → 3.
Floor trigger = USB keypress
Sensor → microcontroller emulating a keyboard. Here that's Space/Enter or the button. Any sensor that fakes a keypress drops in.
